LinguaPal

This NVDA add-on integrates Google Gemini and Groq AI to assist with real-time translations and general chat with AI directly from your NVDA.

Features

  • Translate selected/highlighted text or clipboard content using your selected AI model
  • Fast dual-target language swapping with dedicated hotkey
  • Describe focused window or full screen using AI vision
  • Quick Prompts (Keys 1-9, 0): Run custom, customizable AI prompts on selected or clipboard text and continue chatting
  • Chat with AI with context-aware prompts and image attachments
  • Access all actions via the NVDA Tools menu

Hotkeys & Command Layer

To keep your keyboard free from shortcut conflicts with Windows and other add-ons, LinguaPal uses a Command Layer by default. Press the layer key, release it, and then press a single letter or number:

NVDA+Shift+L: Enters the LinguaPal Command Layer. While active, press:

  • C: Translate selected or clipboard text (translates highlighted text directly if present, otherwise falls back to clipboard)
  • T: Swap translation target language (Primary ↔ Secondary)
  • G: Open LinguaPal chat window
  • D: Describe focused window using AI vision
  • W: Describe full screen using AI vision
  • 1: Quick Prompt 1 (Summarize selected or clipboard text)
  • 2: Quick Prompt 2 (Fix grammar & phrasing)
  • 3: Quick Prompt 3 (Explain simply)
  • 4: Quick Prompt 4 (Rewrite professionally)
  • 5: Quick Prompt 5 (Explain code / error message)
  • 6 to 9, 0: Customizable Quick Prompts 6, 7, 8, 9, and 0
  • S: Open LinguaPal settings panel
  • U: Check for updates
  • N: What's New in this version
  • H: Hear the list of available commands
  • Escape: Cancel and close the layer

Tip: All 10 Quick Prompt presets (1 to 9, and 0) can be configured and customized in the LinguaPal Settings panel. You can also assign dedicated individual shortcuts to any preset in NVDA Menu > Preferences > Input Gestures under the LinguaPal category.

Note: The layer automatically closes after 5 seconds of inactivity. If you prefer dedicated single-stroke shortcuts (like NVDA+Alt+C), you can easily assign your preferred hotkeys to any action in NVDA Menu > Preferences > Input Gestures under the LinguaPal category.

Checking for updates

LinguaPal checks for updates on NVDA startup if enabled in settings. You can also manually check for updates from the settings dialog. If a newer version is available, the add-on will download and install it automatically. This add-on was built very recently, therefore it's recommended that you frequently update the add-on if there are any updates.
