#Version 1.4.0:
What's new:
* Smart Selected/Highlighted Text Translation:
  - LinguaPal now intelligently detects whether text is currently selected or highlighted in any application, document, edit control, or web browser.
  - When triggering translation via Command Layer key C (or your custom translation hotkey), LinguaPal automatically translates the selected text directly—no need to copy it to clipboard first!
  - If no text is currently selected, it smoothly falls back to translating your clipboard content as usual.
  - Added a dedicated "Translate Selected Text" action accessible via the NVDA Tools > LinguaPal menu and assignable to any custom hotkey in NVDA Menu > Preferences > Input Gestures > LinguaPal.
* Quick Prompts Support for Highlighted Text:
  - Quick Prompts (Command Layer keys 1-9, and 0) now prioritize currently highlighted/selected text!
  - Simply highlight any text, sentence, article, or code snippet and press NVDA+Shift+L followed by a quick prompt key (e.g. 1 for Summarize, 2 for Grammar Fix, 3 for Explain Simply, 4 for Rewrite Professionally, 5 for Code Explanation).
  - Automatically falls back to clipboard text if nothing is highlighted.

#Version 1.3.0:
What's new:
* Dedicated Command Layer:
  - All add-on actions are now accessible via a fast, collision-free Command Layer triggered by NVDA+Shift+L.
  - After pressing NVDA+Shift+L, press a single key:
    - C: Translate clipboard text.
    - T: Swap translation target language.
    - G: Open chat dialog.
    - D: Describe focused window using AI vision.
    - W: Describe entire full screen using AI vision.
    - 1 to 9, 0: Run Quick Prompt Preset on clipboard text.
    - S: Open settings panel.
    - U: Check for updates.
    - N: View What's New.
    - H: Hear the list of available commands.
    - Escape: Cancel and close the layer.
  - Automatically times out after 5 seconds of inactivity.
* Quick Prompts (Keys 1-9, 0):
  - Run fast, customizable AI actions directly on your clipboard text:
    - 1: Summarize into clear key bullet points.
    - 2: Fix grammar, spelling, and phrasing.
    - 3: Explain concepts or text in simple, accessible language.
    - 4: Rewrite text in a polished, professional tone.
    - 5: Explain code snippets or error messages with fix suggestions.
    - 6 to 9, 0: Customizable quick prompt slots for your own custom instructions.
  - Automatically opens the LinguaPal chat window with the prompt and clipboard content pre-injected, streaming the response live and allowing seamless follow-up questions.
  - Every preset's name and prompt instructions can be fully customized in LinguaPal Settings.
  - Individual presets can also be bound to dedicated global hotkeys in NVDA Menu > Preferences > Input Gestures > LinguaPal.
* Full Screen Vision:
  - Added Full Screen Vision (key W in command layer) to capture the entire desktop across all displays, perfect for multi-window context or floating tooltips.
  - Users who prefer direct shortcuts can still easily bind their own hotkeys in NVDA Menu > Preferences > Input Gestures > LinguaPal.

#Version 1.2.0:
What's new:
- You can now read changelog of every new version released (both from settings, and tools submenu).
* Interactive Response Streaming Control:
  - "Send" button turns into a "Stop" button during active streaming.
  - Pressing Escape or closing the chat window immediately halts response generation and speech output.
* Chat List Clipboard Copy & Clear History:
  - Press Ctrl+C on any message in the message history list to copy the full message directly to the clipboard.
  - Added a dedicated "Clear History" button to instantly clear the chat history and active image state.
* Clipboard Image Paste Support (Ctrl+V in Chat Input):
  - Pressing Ctrl+V while focused on the chat message input field automatically detects if an image (raw bitmap or copied image file) is on the clipboard and attaches it for the message.
* Configurable Translation Clipboard Behavior:
  - Added a new setting: "Copy translation to clipboard automatically", allowing users to hear translations without modifying their clipboard if desired.
* Grouped Provider Settings Panel:
  - Organized settings into distinct sections for Groq, Gemini, Translation & Language, and General tools with independent API key inputs.
* NVDA Tools Submenu:
  - Added "LinguaPal" submenu under NVDA Menu > Tools with shortcuts to all features, Settings, What's New, and Check for Updates.
* Added an alternative way to access Gemini if it's blocked in a region:
  - Check the check box in the settings panel "If Gemini is blocked on this network, retry through the LinguaPal proxy" if you can't access Gemini otherwise. (Would not work for regions where Cloudflare is also blocked).
Bug fixes & improvements:
- Removed unused code from previous versions of the add-on.
- Made the codebase much cleaner.
